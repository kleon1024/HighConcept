# 风格 C · 女神异闻录5 风格（致敬，全部元素原创）

- **色板**：正红 `#E60012` / 墨黑 `#0B0B0B` / 纯白 `#FFFFFF`；唯一点缀 `#FFD400`，只用在游行队伍里那只「南瓜灯」的眼和嘴上（藏起来的彩蛋）。
- **字体**：标题勒索信拼贴用 Noto Serif SC 900 + Noto Sans SC 900 混排（每字一块旋转色块，黑/白/红互相反色，加错位衬纸和硬投影）；拉丁字用 Anton（NIGHT PARADE · 2026）和 Bebas Neue（标签、跑马灯）。
- **构图**：主轴是 -30° 的跃起对角线：黑色夜空、白色爆炸星、黑色标题斜带、白色游行纸条层层斜切，边缘是撕纸效果，每层都带白描边和偏移阴影。
- **母题**：戴狐面、披风甩开的跃起剪影（伸手够新月）；鬼面贴纸、写着「百鬼夜行」的灯笼串、对话爆炸框「别回头！」、星爆贴纸「今夜限定」、定格点名标签「LEADER 狐」；网点从红到黑渐变、斜线网纸；底部是七只妖怪剪影的游行（唐伞、提灯、鬼、狐、一目小僧、白布幽灵、南瓜头）。
- **怎么动 ①**：转场用「斜切碎片」：画面沿跃起对角线裂成三角碎片飞出；黑色斜板从画外「砸入」，过冲 2–3 帧，同时镜头轻震。
- **怎么动 ②**：角色到跃起最高点时定格：整帧红黑反相闪 2 帧，点名标签带引线弹出，停 1.2 s 以上让人看清，然后恢复运动；披风、围巾、腰带晚一拍才停住。
- **怎么动 ③**：标题按勒索信逐字落版，每字间隔 60 ms，色块先落、字后到，旋转回弹；星爆从焦点放大铺满全屏，直接变成下一场的底色。网点和游行队伍做视差慢移，底部跑马灯一直滚动。
