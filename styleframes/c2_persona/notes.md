## 字体（npm fontsource，本地加载）
- 中文：Noto Serif SC 900（百、今、行、面、子时）/ Noto Sans SC 900（鬼、摘、夜、具）/ ZCOOL QingKe HuangYou（夜、下 — 方块感的「剪报字」）。
- 拉丁：Anton（日期数字）、Bebas Neue（竖排 HYAKKI YAKŌ · NIGHT PARADE · 10.31、SAT）。
- 勒索信规则：每个字一种处理（白底黑字 / 黑底白框 / 裸字描边 / 红底白字），只有「鬼」「摘」是红色重音；字块各自 ±8° 抖动，整句沿 -12° 走。

## 技法
- 全部是代码生成的 SVG（`lib.js` 面具/裂纹/网点/勒索字，`hero.js` 角色），种子随机数，可逐帧复现 → 直接给视频用。
- **角度系统**：板块 -28°（主）、+62°（灰板切边）、文字 -12°。
- **剪纸**：角色和面具整组渲染三次——错位色板（红/黑）→ 22px 白描边（miter 硬角）→ 本体。
- **人物**：黑色硬边赛璐璐，「黑色电影」式布光：只有远侧脸被照亮，近侧眼睛在阴影里发红光；红色隈取一笔；头发是 S 形锥形发束 + 白色网点高光（按到弧线距离改变点径，再被发束分隔线切断）。
- **网点**：只在三处：发梢高光、红带下缘渐隐成黑、灰板上缘渐隐。
- **面具**：狐（主角手里，白）、鬼（红）、般若（白灰）、南瓜灯（黑+红光），四张都是独立剪纸，像游行队伍浮在主角头顶。
- 渲染：`node render.js`（Playwright + headless Chromium，等字体加载完成）。

## 怎么动（视频语法）
1. **面具砸入 + 红黑反相**：每个面具第一次出现时从画外 3 帧砸到位（过冲 6%，回弹 4 帧），同一帧整屏红↔黑反相 2 帧。
2. **斜切碎片转场**：沿 -28° 主斜线把画面切成 3–5 片玻璃，碎片带白边朝运动方向飞出，下一镜头从碎片缝里露出来（碎片就是下一镜头的底板）。
3. **定格点名卡**：每个面具停住时弹出点名卡（黑底锯齿框 + 勒索字名字 + 英文小字），停 ≥1.2 s，背景冻结、只有网点慢慢呼吸。
4. **板块砸入**：标题字块一个个砸下，60 ms 间隔，色块先到、字后到；整句最后一起抖一下。
5. **星爆→下一底色**：红色星爆从焦点放大铺满全屏，直接成为下一镜头的红底。
6. **形状匹配剪辑**：面具的眼洞/轮廓与下一张面具在同一位置、同一大小对切（狐眼→般若眼→南瓜眼）。
7. 结尾：副歌高潮时面具一起被扯下（就是这张图的瞬间），然后标题，最后一拍静音。

## 和被否决的上一版相比
- 一个焦点（半张受光的脸 + 发光的红眼 + 被扯下的狐面），不再是满屏同级元素。
- 认真画的角色：黑白赛璐璐 + 硬边阴影 + 网点高光；手、袖、羽织褶都有结构。
- 网点从「满屏底纹」收成三处功能性用法；加入浅灰板，红色退回重音。
- 勒索字每字一种处理，有主次（鬼、摘为红）；底部 300px 不放任何文字。

## 仍然不如参考的地方（诚实）
