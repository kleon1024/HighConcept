# Style A 研究：东方修仙巨构 × 日系高饱和插画（主题「飞升」）

参考板：`refs/board.jpg`（共 32 张：18 张 pixiv 插画、11 张国产动画剧照或海报、2 张古画、1 张云海照片），来源见 `refs/SOURCES.md`。这些图只用于研究，不进入成片。

## 0. 用户记不起名字的那位画师

“人物插画颜色极其鲜艳的日本画师”，可能性从高到低排：

1. **Mika Pikazo**（pixiv 1039353）：最符合描述。她给《火焰纹章 Engage》、Hololive 等画过人设。画面多用纯黄、群青、品红、荧光绿等满饱和色块，头发分成好几种颜色的发丝，碎片和颜料从一个中心炸开（SuperNova、FLASH BACK）。Nintendo 的访谈也专门夸过她的配色“鲜艳又不扁平”。
2. **藤ちょこ Fuzichoco**（pixiv 27517）：最符合“东方 + 鲜艳 + 繁复”。她以中华风和和风题材、极高的装饰密度和宝石般的饱和色出名（仙桃、幽禅流し、透花回廊）。如果用户记得的作品偏中国风，大概率是她。
3. **LAM**（pixiv 17429）：《takt op.》人设、初音未来“魔法未来 2023”主视觉。配色是黑白灰底上压一抹纯红、品红和金色细线光环（MIRA、冥王星）。鲜艳靠的是克制之后的对比，而不是满屏都是颜色。

另外：**米山舞**（pixiv 1554775）用色散、景深和运动模糊做出很强的动感，可借来做“飞升”的速度感。“Hiroyuki”可能是记混了**今石洋之**（《普罗米亚》导演，米山舞参与了这部片），《普罗米亚》的荧光粉和青色正是这种审美的动画版。横尾忠则、田名网敬一属于迷幻波普海报，天野喜孝属于水彩幻想，都不是“人物插画色彩极艳”的典型。

## 1. 这种画面由什么构成

### 构图
- **一个绝对焦点，通常是圆形**：Mika《SuperNova》由中心向外炸开，LAM《MIRA》用光环框住人物，《大鱼海棠》的圆形天井，《深海》的漩涡。圆是“门”，也是“光核”，正好对应飞升。
- **极端的尺度反差**：画面里的人很小，背后的结构巨大。例子有《杨戬》里的金色法相、《深海》的逆光背影、六七質的玫瑰窗巨构、《姜子牙》的昆仑。人物的高度一般只占画面的 1/8 到 1/12，而且总是站在光的正下方。
- **流线引导**：楼梯、丝带、笔触流、光束都指向光核。《深海》的整片海面是一束束指向太阳的笔触。
- **纵深分层**：暗一点的前景压住画框，饱和的中景是主体，背景最亮、最雾。《千里江山图》和《雾山五行》都是“山、雾带、山、雾带”交替叠下去。

### 明度结构（最关键）
- **画面饱和，但明度有严格秩序**：最亮、最接近白色、饱和度反而低的那一块只留给光核。光核外面一圈是最饱和的颜色（朱、橙、品红），再往外是青和靛，最外面是深色画框。可以记成“白芯 → 饱和环 → 冷色暗框”。
- **暗部不发黑**：阴影是深群青、深紫或深青绿（《姜子牙》蓝夜、《深海》），暗部里还能看到颜色。
- **高调画面**里几乎没有黑色，靠互补色来撑对比（Mika 纯黄底配群青头发，《深海》朱红鱼群配青绿山）。

### 色彩：饱和度怎么控制
- **互补对**：朱砂/橙 ↔ 青绿/青；品红 ↔ 金黄；群青 ↔ 金。
- **中国自带的高饱和体系**：《千里江山图》用的石青、石绿、赭石加金，《永乐宫》用的青绿配朱红。所以“东方”和“高饱和”并不矛盾，青绿山水本来就是矿物色的满饱和。
- **大面积用中饱和，小面积用满饱和**：天空和雾是带色的中间调，最纯的颜色只出现在光边、发丝、丝带和笔触碎片上。
- **彩虹边**：轮廓上有色散和虹彩（米山舞、藤ちょこ）。高光边会从青过渡到品红再到金。

### 线
- **没有统一粗细的描边**。形体靠明度、颜色和逆光边来分开。
- 线只用作**装饰发丝线**，宽 0.5–1.5 px：LAM 的金色细线光环，永乐宫“铁线描”那种又长又匀的细线，藤ちょこ衣纹上的金线。线是“光”或“纹样”，不是“轮廓”。
- Mika 的深色线只出现在重叠的交界处，而且很细、有断口。

### 质感
- 网点（LAM、Mika 的暗部）、胶片颗粒。
- **笔触粒子**：《深海》的“粒子水墨”由成千上万条短笔触顺着流场排列，近看是笔触，远看是光。这是让程序化画面不像矢量图的关键。
- 纸本、绢本的色晕（千里江山图的绢黄底）。

### 光与氛围
- **单一主光源 + 逆光**：边缘光勾出人物和建筑的轮廓，光晕溢出到四周（bloom）。
- **体积光、丁达尔光束**从光核放射出来（《深海》、Mika 的光芒）。
- **大气透视**：越远对比越低，颜色越往雾色靠（黄山云海照片，千里江山图远山）。云海是一层层带亮边的软体积，不是一个个圆球。
- **镜头语言**：光斑、色散、景深模糊、运动拖影（米山舞）。

### 装饰密度
- **疏密对比**：焦点附近非常密（巨环上的刻度、莲瓣、卦象、篆纹），其余地方是大片雾和空气。藤ちょこ 的画再满，也会留出雾或水面让眼睛休息。
- 装饰沿着结构走：环带、栏杆、台阶边。不是散撒的贴纸。

### 人物
- 剪影要优先：飘逸的长袍、长发、披帛形成大的 S 形。边缘光加一点饱和的内衬色就足够了，不需要五官。
- 披帛和发丝是表现运动的主要元素（永乐宫的衣带、《姜子牙》的蓝色丝带）。

### 字体
- 大号竖排毛笔字（《深海》标题的飞白，《哪吒 2》的金色狂草），配一行很小的衬线或无衬线副标题，外加朱印。金色或白色，靠发光与背景分开。

## 2. 上一版错在哪（`styleframes/a_xianxia/frame.png`）

| 问题 | 具体表现 | 修正 |
|---|---|---|
| 云像贴纸 | 气泡状卡通云，带漩涡线和粗轮廓，每团都一样 | 改成 WebGL fbm 体积云海：多层、软边、受光核照亮、顶部有亮边，越远越淡 |
| 粗描边 | 4–6 px 深紫统一描边，所有东西都像剪纸 | 取消轮廓。形体靠明度和逆光边，装饰用 0.6–1.5 px 金色发丝线 |
| 光没有逻辑 | 线性渐变平涂，看不出光从哪来 | 只有一个光核，加 bloom、放射光束、边缘光、暗部冷色反光 |
| 没有空气 | 远近对比一样，看不出层次 | 每一层按深度混入雾色，每层之间夹一条亮雾带（三远法） |
| 饱和度失控 | 整屏品红紫，亮度平均，眼睛找不到落点 | 建立明度秩序：白芯 → 朱橙品红环 → 青靛暗框。满饱和色只用在小面积 |
| 人物粗糙 | 大块剪纸人，太阳脸配八卦贴图 | 人物缩小，变成逆光剪影：长袍、长发、两条披帛顺着 S 形向上飘，只留边缘光 |
| 元素堆砌 | 仙鹤、丝带、彼岸花、印章、青海波同等重要，到处都是 | 一个焦点，密度梯度。青海波不再铺满地面，只作为结构上的发丝纹样 |
| 没有质感 | 干净的矢量色块 | 加《深海》式笔触粒子、胶片颗粒、暗部网点、色散 |
| 字像 PPT | 渐变描边加外发光的楷体 | 竖排行草（志莽行书或类似字体），写字式渐显，金白双色，细线衬线副标题 |

## 3. 技术方案（这些手段能达到上面的效果）
1. **WebGL2 片元着色器**：天空、光核、放射光束和 fbm 体积云海。云顶亮边用高度差近似法线。每一层都按深度混合雾色。
2. **Canvas 2D 结构层**：巨环、台阶、浮空峰、楼阁、人物。用渐变填色加逆光描边，**装饰只用发丝线**。浮空峰的边缘用噪声扰动，并加皴笔笔触。
3. **笔触粒子**：数千条短笔触沿流场（向心漩涡或上升流）排列，颜色从调色板里取互补色，以叠加或屏幕混合模式绘制。
4. **后期**：bloom（多级降采样模糊）、色散、暗部网点、胶片颗粒、暗角、调色曲线，统一在一个 WebGL 合成着色器里完成。
5. **确定性**：所有随机数都带种子。`renderAt(t)` 给出唯一画面，同一套代码既出定帧，也出视频。
