# Style A2 「飞升 · 九重天」 — 风格帧说明

**主题（按用户指示，从「百鬼夜行」改为「飞升」）**：一位修行者独自从云海出发，登上九重天。画面是悬浮的巨构、环形天门、无尽天梯和云海，用高饱和的色彩来画。这是一首纯视觉的诗：雨往天上落，人向光里走。

成片已按这个风格完成，见 `/home/user/HighConcept/art/ascension/`（30 s，`CONCEPT.md`）。这一帧和成片共用同一套渲染引擎：`art/ascension/engine/*.js`，`frame.html` 把它内联打包进来。

## 色板（明度秩序：白芯 → 饱和环 → 冷色暗框）
| 角色 | 色值 |
|---|---|
| 光核白芯 | `#fff6e2` |
| 光晕和背光 | `#ffa040` 橙金，`#ffd98a` 金（发丝线） |
| 天空（上 → 中 → 地平线） | `#050b3e` 夜靛 → `#0f6f9a` 青 → `#ffb25a` 暖金 |
| 环门 | 胎体 `#10307a` 群青，莲瓣交替 `#ff3b2a` 朱、`#ffb01f` 金，宝珠 `#ff4a3a` |
| 云海 | 受光 `#ff7a62` 珊瑚、`#e0488a` 品红，背光 `#22186e` 靛，云边 `#ffe0a0` |
| 浮峰（青绿） | 受光面 `#3fd8b0`、`#127a8a`，背光 `#123a7a`、`#0c0f40`，轮廓光 `#ffd98a` |
| 人物 | 衣 `#2a2a6a`→`#16123e`，衬里 `#ff3b30`，披帛 `#ff3b30`/`#ff2f9a` 和 `#2fe6ff`/`#3a6bff` |
| 点睛色（笔触和碎片） | `#ff3b30` `#ff8a2a` `#ffd36b` `#21d4e6` `#ff3fa4` `#2f6bff` `#18e0b0` |

饱和度的控制方法：大面积用中饱和（天空、云、远景），满饱和色只出现在小面积上（莲瓣、披帛、笔触、碎片、光边）。最亮的白只留给光核。暗部不用黑，而是深群青或深紫。

## 技术
1. **WebGL2 着色器**
   - 天空：三段渐变，叠加笔触向噪声和星点。
   - 光核：圆盘、光晕和噪声放射光束（god rays）。
   - **云海**：8 排分层云带，每排用 fbm 加域扭曲，按“越远越密、越远越淡”做大气透视。云边受光核照亮，内部压暗，色相在珊瑚和品红之间缓慢变化。
   - 前景云墙：屏幕空间 fbm，带轮廓光。
2. **Canvas 2D 结构层（无粗描边）**
   - 环门由多圈组成：0.6–1.6 px 发丝金线、180 格刻度、32 片莲瓣、八卦与篆纹带、144 根背光细射线，内侧有一道受光的厚度弧，所以门有体积。
   - 天梯：逐级透视，踏面横向受光并逐级变化，踢面冷紫，中间是浮雕卷云纹的御路，两侧栏柱和灯。
   - 浮峰：喀斯特石柱群，阶梯状崖壁，冷暖受光和背光两面，竖向皴笔发丝线，顶上有松苔和小亭，底部散入雾中。
   - 人物：逆光剪影，靠偏移得到轮廓光。广袖、长发、发髻，腰间一道朱色窄带，背上一枚金线八卦，两条朱和青的披帛随风扭转。
3. **《深海》式笔触粒子**：900 条锥形笔触沿 9 条彩色轨道绕光核旋转，一部分用叠加混合发光。
4. **Mika Pikazo 式彩色碎片**：碎片、花瓣、符纸条往上飞，加上细光尘。另有雨丝上升和散景水珠。
5. **后期（一个合成 pass）**
   - 4 级 bloom。
   - 亮度色调映射：保住饱和度，高光再做一次逐通道肩部压缩。
   - 色散、暗部 45° 网点（印刷感）、胶片颗粒、靛紫暗角、提升饱和。
6. **确定性**：所有随机数都带种子。`window.renderAt(t)` 对同一个 t 永远给出同一帧，所以定帧和视频是同一套代码。

## 和参考的对比（实话）
- **追平的部分**：明度秩序（白芯、饱和环、冷暗框）、互补色控制、单一焦点构图加巨物尺度、发丝线装饰而不用粗描边、上升碎片带来的“眼花缭乱”、画面密度梯度。放在《深海》和 Mika 旁边，色彩强度和构图张力已经在同一个量级。
- **仍有差距**：参考是手绘或高精度 3D，微观笔触和材质细节（《深海》的油画肌理、藤ちょこ的布料和水面）远比我们密。我们的天梯和环门仍然偏“干净的平面设计”。人物只到剪影级别，不画五官，这是有意的取舍（风格指南里“画不好的地方就抽象化”）。下一步可以给天梯、浮峰和环门胎体加一层程序化的笔触肌理贴图。

## 如何动起来（成片里已实现）
- **镜头**：沿天梯慢推，多层视差（碎片和雨 > 人物和天梯 > 浮峰 > 云排 > 环门）。环门各圈反向慢转，笔触粒子绕光核流动，云排横向漂移，台阶的金边随鼓点逐拍亮起。
- **招牌转场：穿门（zoom-through）**。每升一重天，都从一个圆里穿过去：水滴、天门、门中门、漩涡眼、天井、光核。
- **形状匹配**：雨滴 → 天门；背上的八卦纹 → 天空中的八卦大阵。
- **形变**：金门的莲瓣脱落，扑向镜头，散开后变成五重天的莲海。
- **速度斜坡**：二到四重天每拍穿过一道门，然后在莲瓣处突然放慢。
- **颜色桥接**：光核白化，过渡到纸白底上的书法标题。
