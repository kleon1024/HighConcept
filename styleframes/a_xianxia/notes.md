# Style A 「仙境巨构 · 绚彩东方」— 百鬼夜行 style frame

- **色板**：夜幕 #0B0326 / 靛 #1E0A55 / 紫 #6B2BD9 / 品红 #FF2E9A / 青 #22E4FF / 橘 #FF8A1F / 金 #FFD25A / 朱印 #E8262B / 云粉 #FFB3D9 / 光核奶白 #FFF6CF；规则：暗紫打底，中心金白光核，前景压深紫，青与橘只做点睛。
- **字体**：标题「百鬼夜行」用 Ma Shan Zheng（马善政毛笔楷）竖排，金→橘→品红渐变，配深紫描边和外发光；英文「NIGHT PARADE · 2026」与印章「丙午」用 Noto Serif SC 700。
- **关键母题**：同心巨环（光盘、篆纹带、莲瓣、刻度、城墙窗灯、斜轨环、悬灯）+ 牌楼天门；透视青海波云海；单旋祥云；浮空石峰（皴线、松、悬寺、飞瀑）；无尽天梯上的提灯妖怪剪影；背影仙人（八卦背纹、披帛、灯杖）；仙鹤、孔明灯、彼岸花、半调网点、放射光芒与同心波纹。
- **构图逻辑**：光核+天门是唯一焦点，天梯 S 形引导视线，前景深色人物与深紫云做压角，形成近大远小的巨物尺度对比；文字收在右上，底部 300px 不放关键信息。
- **镜头运动**：慢速推镜沿天梯上行（多层视差：前景云 > 人物 > 山峰 > 海 > 巨环）；巨环各圈层反向慢转，斜轨环绕行；青海波逐行起伏如潮；灯笼呼吸闪烁，披帛与发丝二次跟随。
- **标志性转场**：形状匹配剪辑：仙人背上的八卦纹 → 推近化为天上巨环 → 穿过天门光核进入下一界（zoom-through），每次换场都穿过一道环门。
- **其他转场**：穿云推进（祥云团擦过镜头遮挡换景）；图案变形（青海波 ↔ 莲瓣 ↔ 刻度环互相 morph）；披帛横扫做划像；光核白闪作颜色桥接。节奏上快剪妖怪特写与慢速巨构长镜交替。
