> 文献：AIGA Eye on Design《Acid Graphics are the New Psychedelia》《The Futuristic Gleam of Liquid Metal》(2019)，
> CARI「Acidgrafix」，daisyUI 风格词条，bilibili 专栏 cv16137702，type-01 对 @chrometype 的访谈。

## 1. 酸性设计到底是什么

- **来源**：90 年代锐舞 / techno 传单（故意"反设计"、复印机质感、错位字体 [#46 #47]）+ 千禧年 Y2K 金属 3D + 2010 年代
  网页粗野主义（Brutalism）+ Instagram 社群（@acidgraphix、@chrometype）。David Rudnick 被视为"被反复模仿的源头"；
  CARI 的定义是"规则扭曲、媒介混合的 Instagram grunge：horror vacui、铬字、怪异纹理、自我指涉"。
- **态度**：和 60 年代迷幻的"爱与和平"不同，它是冷的、讽刺的、带重金属气质的（Hoppmann："super organic forms、
  crazy lettering、heavy metal aesthetic"）。所以它天然适合摇滚 / 金属 / 电子乐的视觉。
- **一句话**：**黑（或单一冷底色）+ 液态铬 + 一个酸性强调色 + 极细的技术性排版**。复杂度来自材质与微排版，不来自卡通元素。

## 2. 构成要素

| 维度 | 观察到的规律 | 代表参考 |
|---|---|---|
| **构图** | 一个超大主体（铬物体 / 铬字 / 铬纹样）居中或略偏，四周大面积负空间；或"海报体"——顶部巨大平面字、中部铬物体、底部信息块 | #19 FOREVER、#11–#16、#20 |
| **网格** | 细线框、双层边框、12 栏辅助线、注册十字、刻度尺、圆角标签框；信息"装进格子里" | #25–#28、#33、#39 |
| **配色** | 近单色：黑 / 银灰 / 白为主，**只加一个**酸性色（荧光柠檬绿 #C8FF00 系、电光紫或电蓝）；彩虹全息只出现在铬的反射里，不铺底 | #29、#30、#16、#37 |
| **铬的渲染** | 真正的金属感 = 高对比环境反射：黑白相间的硬边条带、锐利高光点、暗部接近纯黑、边缘有细亮线（菲涅尔）；常带轻微色散 / 全息彩边；表面是"充气 / 熔融"的圆润倒角而不是平面渐变 | #01 #03 #04 #11 #15 #20 |
| **字体处理** | ①液态铬字（熔融、滴落）②锋利的哥特 / 黑字体与部落刺纹融合 ③巨大的平面字被裁切、压在物体后面 ④微型等宽字（坐标、编号、版本号、条码） | #04 #06 #07 #19 #36 #37 |
| **装饰** | 部落刺纹（对称、尖刺、心形 / 蝴蝶形）、四芒星闪光、细线星芒、圆环与轨道、欧普同心圆、网格曲面 | #11–#17 #20 #29 #32 |
| **质感** | 胶片颗粒 / 噪点、塑料袋褶皱、复印机网点、模糊渐变光斑（弥散光）、偶尔的扫描线 | #25 #31 #35 #38 |
| **负空间** | 好作品敢留 40–60% 的纯黑或纯灰；铬物体靠"呼吸"显得贵 | #12 #13 #19 #02 |

## 3. 子风格（找到的分支）

1. **Chrometype 铬字派**：只有一个铬字/铬 logo + 纯色底（#01–#08）。重点全在材质。
2. **Tribal Chrome 部落刺纹派**：对称尖刺纹样、心形、蝴蝶，常配星芒闪光（#11–#17）。Y2K 纹身审美回潮。
3. **Brutalist Acid 粗野海报派**：双线框 + 线稿 + 微排版 + 一个铬/3D 元素，黑底单色（#25–#28、#33）。
4. **Swiss-Acid 编辑派**：大字号瑞士式排版 + 黑字体 + 模糊照片，几乎无铬（Anja Kaiser、Studio Cryo #36–#40）。
5. **Iridescent 全息液态派**：彩虹全息气泡、软体 3D（#15 #31）。最容易做俗，需克制。
6. **Rave Flyer 源流**：1989–93 复印机传单，粗粝、黑白、日期大字（#46–#48）——是"酸"字的出处（acid house）。

## 4. 上一版（`styleframes/b_acid/frame.png`）错在哪

| 问题 | 具体表现 | 本次修正 |
|---|---|---|
| **风格跑偏成合成波 / 赛博朋克** | 紫粉渐变天空、地平线透视网格、霓虹描边——这是 Synthwave 的词汇，不是酸性设计 | 黑底近单色；网格只用平面细线（版式网格），不用透视地面 |
| **"铬"是假的** | SVG 线性渐变 + 描边，没有环境反射、没有体积，看起来像贴纸 | three.js 挤出几何体 + MeshPhysicalMaterial（metalness 1、低粗糙度）+ PMREM 程序化影棚环境（黑白硬光条 + 一条酸绿光条），反射是真实计算出来的 |
| **卡通主角** | 卡通鬼面 + 卡通百鬼剪影，削弱了"冷、贵、锋利" | 主角改为抽象铬物体（被划开的扬声器纸盆 + 部落铬刺 + 铬管波形）与铬字，不出现任何卡通脸 |
| **颜色太多** | 紫、粉、青、绿、黄同时出现，主次不分 | 黑 / 银 / 白 + **唯一**强调色酸绿 #C8FF00，且只占画面 < 5% |
| **过满、无负空间** | 每个角落都塞了装饰、灯笼、胶带、条码 | 至少 40% 留黑；装饰只用于网格与微排版，且全部对齐 12 栏网格 |
| **字体处理平庸** | 粗黑体 + RGB 错位描边 | 中文主字做 3D 挤出铬字（Noto Serif SC 900 的三角衬线像刺）；拉丁大字用平面巨字并做"削顶"裁切（呼应削波）；微型等宽字只做信息层 |
| **故障效果滥用** | 全画面扫描线 + RGB 分离 | 故障只作为转场工具（视频里在重拍上 2–4 帧），静帧只保留颗粒与极轻的色散 |

## 5. 本次执行要点（给自己的检查表）

- 铬：反射里必须看得到**硬边黑白条带**和**一两处酸绿反光**；倒角要圆润（bevelSegments ≥ 6）。
- 布局：顶部平面巨字 → 中部铬主体 → 下部中文铬字 → 底部 300 px 只放微型信息。
- 安全边距 ≥ 70 px；12 栏网格（列宽 70，栏距 ~12）。
- 闪光：四芒星最多 3–4 个，只落在铬高光上。
- 噪点 + 轻 bloom 在 2D/后期层完成。
