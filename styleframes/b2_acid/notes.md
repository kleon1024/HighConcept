# 风格 B2 · 酸性设计 Acid Graphics — 「失真 DISTORTION」

**主题**：简报先后为「百鬼夜行」→「ACID 303」→ 最终由用户定为 **「失真 DISTORTION」**（坏掉的音箱和喇叭如何给摇滚与金属
带来失真音色；配乐为金属摇滚）。静帧直接按最终主题做，以便原样展开成成片（`art/distortion/`）。
主角：被剃刀划开的铬扬声器纸盆（1964 Dave Davies）、正弦波进 → 削波方波出的铬管、部落铬刺、3D 铬字「失真」。

- 研究：`research.md`；参考板：`refs/board.jpg`（50 张，来源 `refs/SOURCES.md`）；对比：`compare.jpg`。
- 渲染：`node render.js` → `frame.png`（headless Chromium + SwiftShader WebGL，约 5 s）。

## 技术

1. **真铬**：three.js r170，`MeshPhysicalMaterial`（metalness 1，roughness 0.03–0.1）。两个程序化 PMREM 环境：
   ①"影棚"——黑房间 + 硬边柔光条 + 顶灯 + 背后轮廓灯条 + 地平线环 + 一条酸绿灯条（扬声器、刺、波形用）；
   ②"经典铬字天空"——上亮下暗、锋利黑地平线、灰地面、一条酸绿地面带（「失真」专用，保证可读）。
2. **液态金属**：`onBeforeCompile` 注入 3D simplex 噪声，按世界坐标扰动着色法线（两层频率，含 `uTime`），
   反射像熔融金属一样流动；纸盆用很小的幅度（保留机械感），铬字中等，刺最小。视频里只要推进 `uTime` 就是"液态铬流动"。
3. **扬声器**：自写剖面的 `LatheGeometry`（防尘帽、11 道纸盆波纹、折环、垫圈、卷边），8 颗铬螺栓；
   **刀口**＝顶点位移（刀口两侧向内卷、向外张）＋ 按 (u,v)→剖面→平面坐标逐像素计算的 alphaMap（带随机锯齿）；
   纸盆背后放黑盘和一片不参与色调映射的酸绿加法光，光只从伤口里漏出来。
4. **部落铬刺**：自写"渐细管"几何（沿三次贝塞尔、椭圆截面、半径按幂律收尖）+ 倒钩，左右镜像。
5. **波形**：`TubeGeometry` 沿 `tanh(G·sin)` 曲线：左侧 G≈0 是正弦（IN），右侧 G=9 是削波方波（OUT），两端藏在扬声器后。
6. **2D 层**：SVG 做 12 栏网格、注册十字、削波巨字、微型字、引线、四芒星闪光；Canvas 做胶片颗粒（overlay 42%）；
   自写 bloom（1/4 分辨率阈值 → 两级模糊 → screen）和**只在边缘出现**的色散（通道与其位移副本做 difference）。

## 和参考的对比（compare.jpg，诚实评价）

- 同一家族了：黑底、真反射铬、微型字、唯一酸性色——和 FOREVER 海报、blakitty 部落铬、uberwolf 线框海报能放在一起。
- 仍弱于参考的地方：①三块大元素（巨字 / 扬声器 / 铬字）纵向堆叠，负空间比 FOREVER 少；②部落刺的造型比 blakitty
  简单、不够"花"；③铬字反射偏亮、黑白条带不如 Chrome Styles 那样凌厉。视频里用镜头分时呈现（一次只给一个主角）来解决①。

迭代记录：v1 铬字发黑、刀口像米色叶片、刺太细 → v2 加液态法线 + 前置柔光箱（铬字太花不可读）→ v3 降低扰动、
刀口收窄 → v4 铬字改用独立"天空"环境（可读性解决）→ v5/v6 地平线穿过字面、颗粒降低 → v7 边缘色散、巨字压暗、铬字缩小留白。

## 怎么动（给成片）

- **液态铬流动**：所有铬面 `uTime` 缓慢推进，反射像水银一样爬过表面；重拍时法线扰动幅度瞬间加大再回落（"被敲了一下"）。
- **削波**：轨线随增益向内收，字和波形被越削越平；增益旋钮转到底时整个画面的亮部被"削平"一帧。
- **刀口**：0.3 s 内从一点拉开（alphaMap 的 halfW 随时间增长），酸绿光从缝里喷出，伴随第一下失真和弦。
- 微型字只做 40–80 ms 错位步进，读数（GAIN、年代）数字滚动。

## 标志性转场

1. **液态铬变形（morph）**：扬声器铬面熔化 → 流成「失真」铬字 → 熔回圆环；同一材质、同一反射，形变即转场。
2. **重拍上的故障 / 切片剪辑**：每个重拍 2–4 帧，画面按横条切片错位 + 边缘色散加大，切到下一镜。
3. **卷曲网格俯冲**：镜头冲进纸盆中心（同心波纹＝隧道网格），从另一端出来进入下一个年代。
4. **圆环匹配剪辑**：纸盆 → 防尘帽 → 旋钮 → 圆形音孔 → 月亮般的光圈，同位置同尺寸的圆连续换义。
5. **波形接力**：正弦线从一镜走到下一镜，在切点处被削成方波，成为下一镜的边框或地平线。
