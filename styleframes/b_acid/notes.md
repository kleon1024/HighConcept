# 风格 B · 酸性设计 Acid Graphics —「百鬼夜行」

- **色板**：底色 #050507 / 深紫黑 #120A22；酸性绿 #C6FF00；电光紫 #8A2BFF；热粉 #FF2E93；冰蓝 #8FE9FF；液态铬 = 天空蓝 #34448E→#D6EAFF→高光 #FFFFFF，地平线暗带 #05030C，地面反射 #5D3A8C→#FF9ED8。
- **字体**：主标题 Noto Sans SC 900（压窄字宽 + 16 层挤出 + 粉/青 RGB 分离 + SVG 镜面光照的液态铬）；拉丁行 Unbounded 900（酸绿实色）；微型字 JetBrains Mono（坐标、条码、序列号、版本号）。
- **核心母题**：铬管线稿般若鬼面（铬角带刻槽、獠牙、酸绿刺青纹）居于「满月光环」中央；光环两侧长出带倒钩的部落铬刺；线框灯笼「鬼」「祭」；地平线上的百鬼剪影行列 + 镜面倒影；起伏的透视线框地面；酸绿警示胶带；四芒星闪光；胶片颗粒 + 扫描线。
- **动·铬字液化**：标题由液态金属滴落、融合成形（置换噪声由强归零），反射带沿字面上下流动；落定后保持 ≥1.2 s。
- **动·故障剪辑**：每个重拍 2–4 帧 RGB 分离 + 横向切片位移（画面中两道 slice 即示意），作为全片的标志性转场。
- **动·网格俯冲**：镜头沿扭曲网格冲向地平线，波纹随低音起伏；行列剪影按 40–80 ms 错位步进，灯笼摇摆作跟随运动。
- **动·圆环匹配剪辑**：光环 → 灯笼横截面 → 鬼面瞳孔 → 满月，同位置同尺寸的圆连续换义；光环刻度盘随节拍旋转，铬刺在切点生长或收回。
