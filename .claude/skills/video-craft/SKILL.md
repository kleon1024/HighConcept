# Video craft (house rules)

Every video should be **有用 useful** (one clear takeaway), **有趣 fun** (at least one moment of delight or surprise)
and **新奇 novel** (one visual or structural idea the viewer hasn't seen). These files hold the rules the user has
taught us; follow them, and when the user gives new feedback, add it to the matching file.

| Topic | File | The one-line rule |
|---|---|---|
| Visual style | [style.md](style.md) | Research references first, build with techniques that reach the quality, compare side by side. |
| Opening | [opening.md](opening.md) | Frame 1 is a question, an anomaly or an impact — never a title card. |
| Narrative | [narrative.md](narrative.md) | Each scene answers the last scene's question and asks the next one. |
| Transitions | [transitions.md](transitions.md) | Something must carry across every cut: a shape, a colour, a motion, a sound. |
| Motion | [motion.md](motion.md) | One focal point, eased and staggered, with time to read. |
| Music | [music.md](music.md) | Real instruments and designed synths, an arc that follows the edit, no rough GM sound. |
| Sound effects | [sfx.md](sfx.md) | Motivated, one palette, no bells/chimes/glitter, ~10 dB under the music. |
| Narration | [voice.md](voice.md) | A real recorded voice (CosyVoice), never pitch-shifted; fast; best of several takes by ASR; the narration drives the timeline to the word; music ~12 dB under. |
| Photos & footage | [media.md](media.md) | Real images only where drawing can't carry it, free-licensed, credited, graded into the style. |
| Ending | [ending.md](ending.md) | Lift it: bookend the opening, widen the frame, land one resonant line. |
| Before delivery | [checklist.md](checklist.md) | Length, legibility, audio, transitions, credits. |

Feedback log (why these rules exist): see the bottom of each file.

Tools in this repo: Remotion projects (`shape-of-sound/`), the score engine `shape-of-sound/music/engine.py`, the sound
library `shape-of-sound/music/sfxlib.py`, the media fetchers `shape-of-sound/media/`, and the Remotion skill
`remotion-best-practices`.
