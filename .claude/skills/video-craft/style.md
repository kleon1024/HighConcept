# Visual style (风格)

Never start a new style from imagination alone. **Research first, then build, then compare.**

1. **Reference board**: collect ≥ 10 real reference images for the style (artists, posters, UI, concept art), look at
   each one, and lay them out in a contact sheet. Keep references for study only — never ship them, never commit them.
2. **Analysis**: write what actually defines the look — composition and value structure, palette and how saturation is
   controlled, line weight, texture, light and atmosphere, ornament density, figure rendering, typography, motion
   grammar — and what our previous attempt got wrong.
3. **Technique that can reach the quality**: procedural SVG alone tends to look like flat clip-art. Use what the style
   needs: WebGL/three.js for real chrome reflections, volumetric light, fog and bloom; canvas noise and soft painting
   for atmosphere; hairline ornament instead of thick uniform outlines; CC photo collage where the style is collage.
4. **Compare side by side** with the strongest references and iterate until the frame could sit next to them.
5. **Show the user the board with the frame**, so they can confirm the direction (and recognise an artist they forgot).

Feedback log: 「a b c 三种你都需要先对风格调研看参考图片再上手」 (first three style frames rejected as not good enough).
