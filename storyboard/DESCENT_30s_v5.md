# 《降 · DESCENT》30 秒 v5：有快有慢、意象经过筛选

## 针对你的反馈改了什么

| 反馈 | 原因 | v5 的做法 |
|---|---|---|
| 不相关的素材拼在一起 | 每个镜头各自孤立，切换时没有任何形状、动作或物体延续下去，金点（主角）在开场之后就消失了 | ① 用**一条主线**串起来：金色的种子从卵里出生，随陨石坠落，变成第一只眼看见的光，再变成纹样、黑洞、梦，最后睁开的眼 ② 加入**转场**：推拉穿越（金色火花穿过切点）、溶接（火接火、网络接梦境）、黑场淡入 ③ 以**眼睛和圆**作为反复出现的母题，靠匹配剪辑连接：日月、复眼、穹顶天眼、黑洞、瞳孔 |
| 没有节奏，应该有快有慢 | 所有镜头都是 1 到 2 拍，速度均匀，音乐密度也均匀 | 整片像呼吸一样，**慢段讲主线，快段承载大量意象**。快段每个切点都落在鼓点上，慢段几乎静止、留白。配乐的动态和画面同步，从 −30 LUFS 的安静到最强处，起伏约 20 dB |
| 画不好的地方用抽象手法 | 鼎像柜子，巴别塔像蛋糕，仿生人像玩偶，羊像一团绒毛 | 这些具象镜头删掉或改成抽象表达（见下） |

## 意象的筛选与替换

**删掉的**：柏拉图洞穴、青铜方鼎、巴别塔、仿生人头像、羊毛电子羊。

**新增两个抽象镜头**：
- **文明之线（纹样的演化）**：一条金线随鼓点变形：甲骨的"卜"裂纹 → 云雷纹 → 希腊回纹 → 巴洛克涡卷 → 电路走线。每种形态留下一道淡淡的刻痕，文明的累积就在画面上看得见。它取代了原来鼎、塔这些零散的道具。
- **机器之梦（星座电子羊）**：神经网络溶接成一片星空，星星连成一只羊。它在命运动机的三下重音上，跳过一道星光栅栏三次；第四次跳到最高点时，散成金色的种子坠落。

**主题的整合**："降"是光（意识）一路向下落的旅程。"眼"是看见，看见就是意识诞生的那一刻。

## 结构（120 BPM）

| 拍 | 节奏 | 段落 | 镜头 |
|---|---|---|---|
| 0–8 | **慢** | 种子 | 金点抽出命运之线，绕成金卵，莲花开放，卵壳裂开（4 秒长镜头）|
| 8–10 | **快** | 宇宙爆发 | 盘古双目化为日月 → 开普勒多面体 → 电子轨道，每个切点一声鼓 |
| 10–16 | **慢** | 坠落 | 陨石载着金光坠入极地海洋，推拉穿越进入冰山：意识沉入潜意识 |
| 16–20 | **快** | 化学 | H₂O → 蛇在第 17 拍咬住尾巴 → DNA → 细胞分裂 → 突触 → 伊甸园 |
| 20–26.5 | **慢** | 第一只眼 | 寒武纪海底，一切静止，复眼接收第一束光 → 闪电 → 被点燃的树：盗来的火 |
| 26.5–29 | 中 | 火 | 焰色反应：锂、钾、铜、钠（命运动机）|
| 29–37 | **最快** | 文明加速 | 甲骨裂纹 → 文明之线 → 帕特农 → 浑天仪 → 穹顶 → 巴别图书馆 → 芯片城市 → 四个 ¼ 拍的闪回。镜头越剪越短 |
| 37–43 | **慢** | 黑洞 | 一切被吞没，整体音高被拽下，之后静音 |
| 43–51.5 | 中 | 梦 | 损失曲面上梯度下降 → 神经网络 → 星座电子羊（命运动机）→ 坍缩 |
| 51.5–60 | **慢** | 觉醒 | 内克尔立方体翻转 → 眼睛睁开，瞳孔是黑洞 → 衔尾蛇闭环 → 回到金点 |

## 技术说明

- **转场**：由时间轴上每个镜头的 `tr` 字段控制。`zoom` 是推拉穿越，加径向模糊，并有金色火花穿过切点。另有 `dissolve`（溶接）、`fadein`（黑场淡入）、`crack`（裂纹切）。
- **时间窗口**：每个镜头的 `win` 字段决定播放它自身动画的哪一段。快段只取最精彩的那一瞬，慢段播放完整动画，等于放慢速度。
- **配乐**：`music/compose.py` 读取 `SECTIONS` 里标的能量等级（slow / medium / fast / fastest）。快段在每个镜头切点自动加一记太鼓、定音鼓和管弦乐重击。
