## v2 里有、30 秒版删掉的内容

雅典学院的人物、圣经手抄本、文学蒙太奇、彭罗斯阶梯、鲁宾之杯。这些元素在 30 秒里分别由别的镜头承担：
- **圣经** → 伊甸园的知识之树和蛇
- **文学** → 巴别图书馆（博尔赫斯）
- **视错觉** → 内克尔立方体和 Shepard 听觉错觉

## 怎么重新生成

```bash
cd film && npm install
node music/compose.js     # → out/score.wav
node render.js            # → out/frames/*.png → out/DESCENT_30s.mp4
node render.js --only 120,450 --scale 0.5 --dir test   # 抽帧预览
```
