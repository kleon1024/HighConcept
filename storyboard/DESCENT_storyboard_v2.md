# 《降 · DESCENT》分镜 v2：艺术短片，按节拍剪辑，无文字

> v1 → v2 改动
> - 定位改为**艺术短片**，取消全部屏幕文字、字幕和标题卡，全片只用画面和音乐讲述。
> - **音乐先行**：120 BPM、4/4 拍，1 小节 = 2 秒，共 104 小节，片长 **3'28"**。每个剪辑点都落在拍上。
> - 镜头数从 32 个增加到 **约 155 个**，平均镜长从 5.6 秒缩短到 1.3 秒，用长镜头和停顿制造对比。

## 2. 剪辑节奏规则

1. **切点只落在拍上**。每章第一个镜头落在该章第 1 小节的第 1 拍。
2. **命运节奏切**：1 拍、1 拍、1 拍，然后一个 5 拍的长镜。每章中段用一次，作为全片的"标点"。表里用 ⚡ 标记。
3. **闪帧**（2–4 帧）只在 V 章用，作为极繁的视觉噪声。表里用 ✦ 标记。
4. **气口**：每章最后一拍是静音或黑场，然后裂纹劈开画面，落在下一章第 1 拍。
5. **镜头密度曲线**（平均镜长）：序 4s，I 1.6s，II 1.6s，III 1.1s，IV 1.3s，V **0.4s**，VI 1.6s，VII 5.3s。

时码写法：`b23.3` 表示第 23 小节第 3 拍；"拍"列是镜头时长，1 拍 = 0.5 秒。

## 4. 我最擅长的实现方式：全代码生成（画面与音乐共用一条时间轴）

我最拿手的是**用代码写画面和音乐**：WebGL/GLSL 着色器加程序化几何生成画面，数字信号合成生成音乐。这正好对上本片要的"全息网格 + 粒子 + 黑金 + 卡拍剪辑"。

```
score.json（节拍表：104 小节 × 每个镜头的起点和拍数）
   ├─► music/ 程序化合成 → score.wav
   │     FM 合成：玻璃钟、编钟（不和谐分音）
   │     加法合成：管风琴、泛音列
   │     Shepard–Risset 下行滑音、颗粒化冰裂声、心跳底鼓、比特压缩八音盒
   └─► visual/ Three.js + GLSL → 逐帧渲染（无头 Chromium）→ PNG 序列
         线框发光、扫描线、色散、泛光
         GPU 粒子：吸附与崩解
         光线步进（raymarch）：黑洞透镜、电子云、SDF 多面体
         数学几何：苯环、DNA、晶格、本轮、损失曲面（真实的 SGD 轨迹）
                        ↓
                ffmpeg 合成 → DESCENT.mp4
```

- **为什么这样做**：画面和音乐读同一份节拍表，所以每个切点、每次闪光、每次变形都能逐帧对准音乐，而且整部片子可以完全复现。
- **坦白说明**：
  - 当前环境没有 GPU，只能用软件渲染。1080p 可以做，但要慢慢渲；4K 需要放到有 GPU 的机器上跑。
  - 程序化音乐在电子、氛围、打击乐上效果很好；管风琴和合唱是合成音色，做不到真乐团的质感。之后如果要换成真人作曲，节拍表可以直接沿用。
  - 风格会偏"数学之美、抽象全息"。盘古、仿生人、羊这类具象角色会做成线框和粒子的符号化形体，不会是写实造型。

**建议的推进顺序**
1. **配乐 + 动态分镜**：先做出完整的 3'28" 音乐，配上低精度的占位画面，卡点剪好，用来确认节奏。
2. **风格帧**：先精做 4 帧，P03 金胎、II14 苯环蛇咬尾、V40 黑洞、VII04 鲁宾之杯，锁定视觉。
3. **逐章精渲染**，最后合成。
