# 《降 · DESCENT》30 秒版 v4：重写版

## 为什么重写

上一版（v3）的问题：
- **建模太粗**：所有物体都是线框加粒子。
- **配色单一**：整片只有黑和金，分不出画的是什么。
- **配乐太弱**：纯代码合成，音色单薄。

v4 参考了网上 Opus 5.5 代码动画的做法，按以下原则重写：

| 原则 | v4 的做法 |
|---|---|
| 一个镜头只讲一件事，画面留白 | 每个镜头只有一个主体，而且这个主体要一眼认得出来 |
| 颜色跟着剧情走 | 每章一套色板（见下表），金色只作为贯穿全片的点缀 |
| 用真实的 3D 材质 | 物理材质：金属、青铜铜锈、大理石、冰、玻璃、骨、有机组织；软阴影；ACES 色调映射；运动模糊 |
| 禁用滥用的特效 | 不用粒子爆炸、冲击波环、RGB 分离、镜头光斑；章节转场只用一道细金裂纹，配极弱的白闪 |
| 音乐和画面锁在同一条时间轴上 | 用真实采样的管弦乐（FluidSynth + FluidR3 GM 音色库），再叠加合成音效，响度母带到 −14 LUFS |

**全息网格**这一原始风格要求保留了下来，但改成"扫描成形"的效果：物体先以一层金色全息线框出现，扫描线扫过的地方变成实体材质。它只是点缀，不再是唯一的表现手法。

## 配乐（music/compose.py）

**调性与和声**：C 小调。和声走向 Cm → A♭ → E♭ → B♭ → Cm/Fm → 全音阶上升（C→D→E→F#）→ 最后落在 C 大调。

| 段 | 配器与关键处理 |
|---|---|
| 序 | 钢片琴奏出种子动机（G-C-E♭-D），低音弦乐持续音，合唱轻轻呼吸 |
| I 振 | 弦乐铺底，钢琴奏动机，竖琴琶音；轨道变形的三拍各配一声钢片琴；定音鼓滚奏推向陨石 |
| II 冻 | 拨弦奏出 6 音"苯环"循环，钟琴点出 H₂O；蛇咬尾巴那一刻管弦乐齐奏重击 |
| III 生 | 16 分音符断奏弦乐，定音鼓模拟心跳；第一只眼时全部停下，只剩钢片琴一个音 |
| IV 盗 | 太鼓驱动；圆号配管弦乐重击奏出命运动机 G G G E♭ |
| V 繁 | 管风琴、合唱、圆号、鼓组全开，每两拍升一个全音；闪帧段用切片重击；黑洞段整体弯音下坠 12 个半音 |
| VI 降 | 钢琴像优化器一样逐级下降并收敛；钢片琴奏摇篮曲；电子羊段用钢片琴奏命运动机 |
| VII 觉 | 一次吸气，C 大调全奏（弦乐、合唱、竖琴），管钟一击 |

**音效层（numpy 合成）**：每章开头的低频重击、上升噪声、雷声、龟甲裂响、Shepard 下行滑音、吸气声。

**母带**：−14 LUFS，峰值约 −1 dBTP。

## 生成方式

```bash
cd film
python3 music/compose.py                  # 配乐：MIDI → FluidSynth → 合成音效 → 母带
node render.js --blur 3                   # 1080p30，3 个子帧运动模糊 → out/DESCENT_30s.mp4
node render.js --only 30,450 --scale 0.5 --dir test   # 抽帧预览
```
