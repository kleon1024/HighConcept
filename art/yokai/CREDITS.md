# Credits — 百鬼夜行 · 今夜，摘下面具

All imagery is original, drawn in code (`src/lib.js`, `src/hero.js`, `src/scenes.js`, `src/yokai.html`).
No Atlus/Persona assets, logos, characters or phrases are used; the reference images studied for the style live only in
`styleframes/c2_persona/refs/` (gitignored) and never enter the video.
