# 《御剑》风格调研

参考拼板见 `refs/board.jpg`（29 张），来源见 `refs/SOURCES.md`。
全片要同时成立三件事：**巨构的尺度**、**仙侠的语汇**、**东方的飘渺**。
日系插画（藤ちょこ）的高饱和只放在很小的面积上，不再整屏套色。

## 1. 每张参考图教会了什么

| 参考 | 看到了什么 | 用在哪里 |
|---|---|---|
| 范宽《溪山行旅图》 | 主峰占画面上三分之二，压迫感来自**垂直的巨物**和画面底部一列米粒大的行旅；山脚用一条雾带把巨物和人分开 | 开场仰拍：建木占右三分之一，人和鹤只是芝麻大的点，中间隔着云海雾带（高远） |
| 郭熙《早春图》 | 三远法同在一幅里：高远看主峰，深远看山谷，平远看远处的水；雾是一层一层的，**每过一层雾，明度就提一级** | 场景按深度分层，每一层都加一条雾带，越远越亮、越青，暗部只留在最近的一层 |
| 王希孟《千里江山图》 | 石青、石绿叠在赭石底上，饱和度很高，但只出现在山头；天和水几乎是素绢色 | 中景山体用石青和石绿，山脚用赭色，天空是带一点米黄的青白 |
| 《凡人修仙传》黄枫谷 | 张家界式的石柱浮峰，**顶光是暖金色，雾是冷的淡青紫**，宗门楼阁贴在峰顶，雾海把每座峰的根部都吃掉 | 浮岛的底部融进雾里，顶上打暖光，楼阁用朱红屋檐配白墙 |
| 《哪吒之魔童闹海》云山与玉虚宫 | 整个画面高调：白色岩壁、绿松针，远山退成近白的青色；玉虚宫用白和淡青来表现神圣，人小得像一粒点 | 天光和雾都偏亮偏青；天门剪影用淡金和白，不做成暗色剪影 |
| 《遮天》《完美世界》巨柱 | 巨物上有自然侵蚀的痕迹（裂纹、苔藓），四周有鹤绕飞，前景放一个小人背影，用尺度落差制造震撼 | 建木树皮做出纵向纤维和苔痕，鹤群从旁边掠过，用来提示尺度 |
| 《姜子牙》雪原巨像、昆仑 | 断裂的巨构横躺在雾里，残骸只剩轮廓，远处的东西全部推成单色 | 天梯断开以后，残段在雾里慢慢下坠，远处的残骸都推成单色剪影 |
| 《长安三万里》乘鹤、仙人云海、水墨崖 | 人在崖边，一轮朱红的太阳，大面积留白；乘鹤飞行时，衣袍和飘带被风扯成长长的曲线 | 崖边那一场：她站在右下角，左上方大面积留白；飘带要拉成长曲线 |
| 《新神榜：杨戬》蓬莱、楼城、金身 | 楼阁层层叠叠，装饰非常密，但都在中远景，近景反而干净；金光用来点亮神性 | 楼阁的密度只放在中景；终场的金光是对“天”的回应 |
| 《雾山五行》 | 水墨笔触直接作为体积：笔触的方向就是形体的方向 | 岩石材质叠一层沿斜向的笔触噪声（皴擦），不用均匀的数码渐变 |
| 《BLAME!》致敬图和巨构概念图 | 巨构的语言是**重复的单元**（梁、柱、管、链）一直延伸到雾里看不见尽头，镜头总是仰视或俯视 | 天梯做成重复的巨梁（像梯子的横档）和链环，一层一层向上，消失在光里 |
| 藤ちょこ《仙桃》《水簾の巫女》《大渓谷》 | 大面积是干净的中性色或青绿，**宝石色只出现在小面积**：朱红栏杆、金饰、花、水光；装饰的密度来自很多小高光，而不是大色块 | 朱红只用在栏杆、屋檐、飘带和印章上；金色只用在光点和轮廓光上；剑光是青白色；桃花只是很小的点缀 |

## 2. 这个风格由什么决定

- **构图与明度**：竖幅、不对称。巨物偏向一侧，另一侧大面积留白。明度结构是“浅底深物”：天和雾是高调的，物体越近越深；
  每隔一层雾，明度就提高一档（三远法）。远景里人只有画面高度的 1/20 左右。
- **色彩与饱和度控制**：基调是青白色的天、石青和石绿的中景、赭石色的山脚，加上暖金色的阳光。
  饱和度集中在小面积上：朱红（楼阁、飘带、印章）、玉色、剑光的青白、金色的火花。
  雷劫一场的底色是深石青，不用紫色，闪电是金白色。全片不出现紫红或品红的整屏色调。
- **线与质感**：没有粗描边。形体靠明暗、轮廓光和雾来分开。岩石上叠斜向的皴擦笔触噪声，画面加一层很细的纸纹和颗粒。
- **光与空气**：深度雾一律融向雾色（不是融向黑色）；高度越低雾越浓（云海）；阳光从侧上方来，给物体打暖色轮廓光；
  雾里的光要做出体积感（光柱、泛光）。
- **装饰密度**：只放在中景，比如楼阁的檐角、灯笼、链环、梁头的斗拱。近景要干净，人物轮廓要清楚。
- **人物**：背影为主，侧逆光。轮廓上的标志是长发、发髻、宽袖法袍、长长的朱红披帛和背上的剑。
  飘带、头发和衣摆都要有二次运动（随风甩动，再慢慢落定）。
- **字体**：说明字用细宋体（思源宋体），放在上三分之一，字距拉开，墨色或白色加一点雾光；片名用行草书法，配一方朱红印章。
- **运动语法**：真正的三维镜头运动，包括仰拍上摇（高远）、穿越飞行（深远）和拉远升起（平远）。
  近景、中景、远景之间要有视差；巨物要慢，人要快；剪辑落在鼓点上。

## 3. 题材必备元素（每个镜头至少带一样）

御剑（脚下看得见剑，身后拖着光迹）、浮空宗门山（楼阁和瀑布）、云海、仙鹤、锁链悬岛、雷劫、法袍飘带、天门宫阙剪影、
巨构（建木天梯：巨大的树干、横档巨梁、链条、断口）。

## 4. 第一版《飞升》错在哪里

1. **意义不明**：「雨往天上落」只是一个比喻，没有人物、没有目标、也没有阻碍。→ 这次讲一个能用一句话复述的故事：
   天梯断了，她跳下去，剑接住了她，所有人都学会了自己飞。
2. **没有题材语汇**：没有御剑、没有宗门、也没有可感的巨构，天门只是居中的平面曼陀罗。
   → 这次每个镜头都有仙侠元素，巨构是一个连续的三维世界，用镜头运动让人感到它的尺度。
3. **配色错误**：整屏套用 Mika Pikazo 式的紫、品红和橙。→ 这次以青白和石青石绿为基调，饱和色只用在小面积上。
4. **动画错误**：居中的海报构图，加上圆环和八角形的缩放隧道。→ 这次用 three.js 搭真三维场景，做高远、深远、平远三种镜头运动，
   人物有真正的动作：站、迈步、坠落、被接住、飞、破雷。

## 5. 技术路线

three.js 真三维场景，渲染页面提供确定性的 `renderAt(t)`，用 Playwright 逐帧截取。
- 建木用位移圆柱加纵向纤维的树皮着色器；梯子的横档、斗拱、灯笼和链环都用实例化网格。
- 浮岛用噪声位移的倒锥体，顶面放松树、楼阁和瀑布。
- 材质是自定义的绘画式着色器：暖光和冷环境光的渐变、轮廓光、皴擦噪声、深度雾和高度雾，雾都融向雾色。
- 云用多层 fbm 公告板，加一张云海平面。
- 远山用程序绘制的画布层。
- 后期依次做泛光、轻微色散、颗粒和纸纹。
- 人物用 Canvas 2D 程序绘制成精灵贴图，放到场景里作为公告板；头发、飘带和衣摆都用程序驱动。
