# 《初光 · FIRST LIGHT》

30 秒，1080p30，无文字。讲意识的诞生：宇宙学会了"看"。

## 概念

全片只有**一个主体**，配一次**连续的运镜**，它不断变成下一样东西：

**一点光 → 宇宙网 → 细胞 → 心智 → 眼睛 → 眼里那一点光**

镜头之间不拼接互不相关的素材，每一刻都是上一刻的变形。结尾瞳孔里映着的，正是开头那一点光，所以可以无缝循环播放。

## 结构与节奏

节奏不靠剪辑速度，靠一条**加速的心跳**：速度从 60 BPM 一路加到 170 BPM，然后戛然而止。画面里的每一次脉冲，和音乐里的每一个音，都读取同一张速度表（`src/plan.js`）。

| 时间 | 幕 | 画面 | 声音 |
|---|---|---|---|
| 0–5 秒 | 虚无 | 量子泡沫在黑暗里呼吸，虚粒子明灭；第 2 秒一点光亮起，周围有闭弦在振动 | 低音持续音，零星的钢片琴；光亮起时一声 C6 |
| 5–10 秒 | 物质 | 光像墨汁入水一样流出，沉淀成宇宙网：金色星系节点，紫色纤维；镜头俯冲进其中一个节点 | 竖琴流动，弦乐铺开，心跳 60 BPM |
| 10–17 秒 | 生命 | 节点变成一个细胞，在拍点上分裂：1 → 2 → 4 → 8 → 16 | 每拍一记马林巴拨弦，圆号唱出主题，分裂时竖琴加钢片琴 |
| 17–25 秒 | 心智 | 细胞长出神经元，信号沿突触奔跑，越来越快，最后全网同步放电 | 断奏弦乐和钢琴跟着每个信号，太鼓跟着每一拍，到高潮时全奏 |
| 25–30 秒 | 看见 | 静音；神经纤维化作虹膜，眼睛睁开，瞳孔里是最初那一点光 | 一次吸气，C 大调随睁眼展开，最后又一声 C6 |

## 制作方法

- **画面**：Three.js 和 GLSL，在无头 Chromium 里逐帧渲染。粒子位置和信号脉冲都在 GPU 着色器里按时间计算，所以每一帧都可以完全复现。
  - 虚无和眼睛两幕是全屏着色器。
  - 宇宙网是 16 万个粒子。
  - 细胞用 Marching Cubes 等值面生成，分裂时会有颈缩。
  - 神经网络是程序化生长的树突，信号按速度表沿着树突传递。
- **配乐**：`music/compose.py` 用采样管弦乐（FluidSynth + FluidR3 GM 音色库）加上合成的音效层，母带到 −14 LUFS。

```bash
python3 music/compose.py
node render.js --blur 3 --workers 3   # → out/FIRST_LIGHT_30s.mp4
```
